# Autonomous SumoBot

An autonomous Arduino Nano-based SumoBot using ultrasonic and IR sensors for opponent detection and edge avoidance.

## Features
- Startup delay
- Patrol mode
- Attack mode
- Edge detection
- Reverse and pivot recovery
- PWM motor control

## Repository Structure
See folders `code`, `docs`, and `hardware`.

## Hardware
- Arduino Nano
- Cytron 2-channel Motor Driver
- 2x 12V DC Gear Motors
- Grove Ultrasonic Sensor
- 2x IR Line Sensors
- Buck Converter
